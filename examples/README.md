# examples/ — archived, not the product

Nothing in this folder runs, is served, or describes GitBounty as it is built.

## `web/`

The original vanilla `index.html` / `styles.css` / `script.js` landing page, from before the site was
rebuilt in Next.js. It is kept because it is the visual specification the current site was ported from, and
because deleting a teammate's work to tidy a folder is the wrong trade.

**Its copy describes the money-and-escrow product that was pitched and never built** — "funds move into
escrow immediately", "releases the escrow straight to the contributor's wallet", webhook-triggered payouts,
commission tiers. None of that exists anywhere in this repository: there is no escrow contract, no wallet,
no chain, no token and no payment path. GitBounty awards **points**.

The live site is [`../frontend/web/`](../frontend/web). What the product actually is:
[`../PRODUCT.md`](../PRODUCT.md). The pitch this page was written for, with the same caveat:
[`../docs/original-money-pitch.md`](../docs/original-money-pitch.md). What a safe paid phase would really
require, as a proposal and not a plan: [`../docs/future-paid-bounties.md`](../docs/future-paid-bounties.md).
